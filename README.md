# Codex切号器

面向 Windows 的 Codex 多账号管理工具，支持额度查看、无感切号和吸顶小面板。

## 功能特色

- **超小体积**：文件体积1.16M，运行内存占用约6M。
- **无感切号**：连接就绪后，正常切换保持 Codex 窗口及后台进程运行。有对话进行时，等待当前轮结束后切换，下一轮使用所选账号。
- **额度总览**：查看各账号的 5 小时、每周剩余额度、重置时间及订阅信息。
- **批量与自动刷新**：支持单账号、全部账号刷新，可设置刷新间隔与并发数量。
- **大小面板切换**：完整窗口方便管理，350px 小面板方便查看；各自记住位置与吸顶状态。
- **吸顶与托盘**：吸顶隐藏、顶部悬停唤出，支持最小化到托盘。
- **隐私遮挡**：一键隐藏账号邮箱，方便截图与录屏。
- **原生单文件**：Rust + Win32 + Direct2D + DirectWrite，无需安装 .NET、WebView2 或 Visual C++ 运行库。
- **在线更新**：支持检查新版，经用户确认后更新切号器。

## 开始使用

1. 准备 Windows 10/11 x64，并安装 Codex 客户端。
2. 从本仓库的 Releases 页面下载 `Codex切号.exe`，直接运行。
3. 通过「添加账号」登记当前登录、浏览器登录新账号，或导入账号凭据文件。
4. 查看额度，选择需要使用的账号并确认切换。

首次连接缺失时，工具会尝试自动接通 Codex，必要时重新打开客户端。连接就绪后，正常切号保持客户端运行。

当前界面提供简体中文。

## 工作方式

切号器通过标准输入输出桥接原版 Codex 后台，不修改 Codex 安装文件。切换时验证后台实际认证信息，通过后才提交本地凭据与账号列表；失败时回滚。

无感切换作用于已接入桥接器的本机 Codex Desktop 后台。云端任务、远程主机及独立运行的 CLI 进程不随之切换。

## 本地数据

账号凭据、账号列表和设置保存在 `%LOCALAPPDATA%\CodexSwitch\`。凭据文件包含登录授权信息，请妥善保管，不要放入公开仓库或随问题反馈上传。
